- 키워드 상세의 "마지막 수집"은 마지막 시도(예: 제한 초과 실패)를 보여 준다. 그 위에는 마지막 성공 값(10,000 · PC 2,000 · 모바일 8,000)이 그대로 남는다
- 클릭 · CTR · compIdx 는 `import_rows.payload` 에만 저장한다. Score V1 입력으로 바꾸지 않았다
- **인증정보 노출 검사** [실제]
  - 프로덕션 빌드의 브라우저 파일: `NAVER_SEARCHAD` 이름 · 시험 키 값 0
  - 확장 프로그램 결과물: 0
  - 개발 모드 브라우저 파일: 키 값 0. 단 개발용 소스맵(.map)에 설정 안내 문구 속 **환경변수 이름**만 있다 (값 아님, 배포에는 없음)

| 필드 | DB (`product_snapshots`) | `/import` 상품 데이터 |
|---|---|---|

| `sales_period_days` | 있음 (> 0) | 있음 — 판매량이 있으면 컬럼 또는 화면 입력값이 **필수** |

### 5-2. 실제 가져오기 시험 (`[TEST]` 상품 1개)

| 파일 | 출처 · 신뢰도 | 결과 | DB |
|---|---|---|---|
| ① 추정 판매량 (헤더 "판매량" → 직접 "추정 판매량" 선택, 기간 30 입력) 3개 날짜 | 직접 입력 · C | 3행 저장 | 09-01 300 · 09-15 330 · 10-01 360 (`sales_estimated`, 기간 30) — 날짜별 스냅샷 3개 |
| ② 실제 판매량 · 기간 28 · 전환율 3% | WING · A | 1행 저장 | `WING_SESSION` 별도 행: `sales_actual 340` · 기간 28 · 전환율 0.03 · **추정 칸 NULL** |
| ③ ① 과 같은 파일 다시 | — | **실행 버튼 막힘**: "같은 파일을 이미 가져왔습니다 … 다시 가져오려면 이전 가져오기를 먼저 되돌리세요" | 변화 없음 |
| ④ 같은 날짜 · 같은 출처, 판매가만 (전환율 칸 비움) | 직접 입력 · C | 1행 저장 | 10-01 MANUAL 행: 판매가 9,900 추가 · **추정 판매량 360 유지** · 전환율 NULL 유지 (0 아님) |

- **추정치가 실제 판매량을 덮어쓰지 않는다.** 칸이 다르고(`sales_estimated` / `sales_actual`), 출처가 다르면 자연키가 달라 행도 따로 생긴다
- 출처 · 신뢰도 · 수집일이 행마다 보존된다

### 5-3. Score 판매 요소 연결 (상품 상세 미리 보기) [실제]

| 요소 | 화면 | 손 계산 |
|---|---|---|
| 판매량 | **81.84** — "월 환산 판매량 중앙값 364개 (1개 상품, 실제)" | 실제 340 × 30 ÷ 28 = 364.3 → 300(80)~1,000(100) 구간 = 81.84. 실제가 있으면 추정보다 우선 |
| 판매 성장 | **62** — "추정 판매량 2026-09-01 → 2026-10-01 +20.0%" | 같은 종류(추정)끼리만 비교, 30일 간격 ≥ 7일 · 90일 안 → +20% → 0(50)~0.5(80) = 62. 실제는 1회뿐이라 실제끼리는 비교하지 않음 (섞지 않음) |
| 전환율 | **50** — "전환율 중앙값 3.0%" | 0.03 → 0.02(40)~0.05(70) = 50 |

판매 데이터를 넣으니 판매량 · 판매 성장 · 전환율 세 요소가 살아났다.

## 9. 기존 기능 회귀 여부 · 발견한 문제

- **회귀 없음:** Extension · `/import` · Dashboard · Profit · Score 테스트 전부 통과. `/import` 이력에 네이버 job 이 "실패 · 부분 성공 (오류 있음) · 완료" 로 함께 표시된다 [실제]
- 실사용 중 발견한 것
  1. **(고침) 헤더 "판매량집계기간"이 자동 인식되지 않음.** 화면의 필드 이름("판매량 집계 기간(일)")과 같은 글자인데 별칭에 없었다. 판매량 파일이 "기간 필요"로 멈췄다. 별칭 2개를 추가하고 회귀 테스트를 넣었다
  2. **(고침) 요청 없이 건너뛴 경우에도 "모의 서버 응답" 이라고 표시.** 머리말을 "개발 모의 서버 — 실제 네이버 아님" 으로 바꿨다
  3. **같은 날 수동 재시도는 값이 같아도 "갱신"으로 센다.** 기존 스냅샷 함수의 동작이다 (PHASE 10 보고서와 같은 사안, 데이터 중복은 없음)
  4. **앱 브라우저 로그인 만료.** 시험 중 사용자 재로그인 1회
