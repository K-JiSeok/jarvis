## 3. 실제로 변경된 동작

1. **후보 검토 (/discover 상품 카드)** — 모든 상품 카드에 단계 표시와 버튼이 생겼습니다.
   - 버튼: [후보로 선택] · [검토 제외] · [소싱 시작] · [소싱 보류 (후보로)] · [선택 해제 · 제외] · [제외 취소]
   - 누를 때만 바뀌고, 상태 이력은 기존 트리거가 남깁니다.
   - 메모는 기존 관심상품 메모를 그대로 씁니다 (/watchlist, 상품 상세).
2. **일괄 소싱 시작 (/discover 상단 단계 패널)** — 후보 목록에서 체크한 것만 [소싱 시작]합니다. 후보(WATCHING)가 아닌 상품은 건너뛰고 사유를 알려 줍니다.
3. **소싱은 대상 상품만**
   - 검색 링크(1688 · 타오바오 · Alibaba)와 상세 원가 요약은 소싱 대상 상품 카드에만 나옵니다.
   - 대상이 아닌 카드에는 "소싱 대상 아님 — 이유"가 나오고, 기존 공급 후보와 원가 기록은 그대로 보여 줍니다.
4. **자동 실행**
   - 소싱 대상이 0개면 소싱 단계를 SKIPPED 로 기록합니다.
   - 대상이 있으면 그 상품만 검색어 생성 · 연결 재계산 · 상세 원가를 합니다.
   - 실행 기록에 전체 상품 · 대상 · 건너뜀 · 대상 밖 연결 수 · 성공 · 실패를 남깁니다.
5. **공급 후보 자동 연결** — 대상 상품 없이 저장한 후보는 소싱 대상과만 비교합니다. 대상이 0개면 후보만 저장하고 연결하지 않습니다.
   - 확장 프로그램이 상품 정보와 함께 저장하는 경우(대상 상품을 찍어 저장)는 사용자가 직접 한 동작이라 이전처럼 연결합니다.
6. **공급업체 비교 보완**
   - 정렬: 내가 선택한 후보 → 일치도(확정 > 유사 > 불명확) → 제외 순. 가격순이 아니고, 점수나 등급은 만들지 않습니다.
   - 판매자 정보(사이트 표시 연차 · 평점 · 위치)를 표시하고, 값이 없으면 "확인 불가"로 둡니다.
   - 거래 · 인증 · 시험성적서 자료는 수집하지 않으므로 "확인 불가"로 표시합니다.
   - 최종 선정은 사용자가 [선택]으로 합니다.
7. **원가** — 기존 `cost-detail-v1` 을 그대로 씁니다.
   - 주문 수량별 표에 필요 자금(판매 1개 도착 원가 × 판매 단위 수)을 추가했습니다. 미확인 비용을 뺀 하한이라 "실제는 더 큼"으로 표시합니다.

## 12. 향후 제안 (구현하지 않음)

- **[제안] ① 선택 해제 ≠ 검토 제외** — 지금은 둘 다 관심상품 DROPPED 하나로 기록됩니다. 구분하려면 관심상품에 `REJECTED` 단계를 추가하는 마이그레이션이 필요합니다.
- **[제안] ② 공급업체 선택 · 해제 이력** — [선택]하면 원가 이력(`supply_cost_snapshots`)과 상세 원가 이력에 그 시점의 공급 후보가 남습니다. 하지만 선택을 해제하거나 제외한 시점은 남지 않습니다. 별도 이벤트 기록이 필요합니다.
- **[제안] ③ 샘플 검증 · 초도 발주 단계** — 관심상품 `TESTING` 을 샘플 단계로 쓰고, 체크리스트(샘플 수령 · 품질 확인 · 인증 서류)를 붙이는 방안입니다. 자동 완료는 하지 않습니다.
- **[제안] ④ Alibaba.com Buyer Sourcing API 신청** — 소싱 대상 상품만 이미지 · 카탈로그 검색에 쓰는 방안입니다 (PHASE 20 11절).
- **[제안] ⑤ 원가 → V1 마진 연결** — PHASE 20 제안 ① 그대로입니다.
