1. 프로젝트 폴더를 `D:\project\jarvis` 로 옮긴 뒤, Claude 앱 사이드바 "Scheduled" → "JARVIS 매일 오전 상품 3개 추천" 작업 안의 폴더 경로를 `D:\project\jarvis` 로 바꾼다.
