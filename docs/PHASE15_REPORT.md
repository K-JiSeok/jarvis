## 7. 내가 직접 수행해야 할 작업

### 7-1. 네이버 검색광고 API 키 적용

1. 검색광고 관리자센터(searchad.naver.com) → **도구 → API 사용 관리** 에서 세 값을 확인한다
   - **액세스라이선스** (= API 키)
   - **비밀키**
   - **CUSTOMER_ID** (고객 ID, 숫자)
2. 프로젝트 폴더의 `.env.local` 을 메모장 등으로 열어 맨 아래에 세 줄을 추가한다 (따옴표 · 공백 없이)
   ```
   NAVER_SEARCHAD_API_KEY=액세스라이선스값
   NAVER_SEARCHAD_SECRET_KEY=비밀키값
   NAVER_SEARCHAD_CUSTOMER_ID=고객ID숫자
   ```
3. 저장하고 Claude 에게 "키 넣었어"라고 알린다. 개발 서버 재시작과 실제 호출 검증은 Claude 가 한다
4. 주의
   - 키 값을 채팅에 붙여 넣지 않는다
   - `.env.local` 은 git 에 올라가지 않는다 (확인됨)

### 7-2. 판매량 · 전환율 출처 정하기

- WING 에 상품 1개 이상 등록 → 판매분석 화면 확인
- 또는 외부 도구의 실제 내보내기 파일을 하나 준비한다
