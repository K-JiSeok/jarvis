## 6. 남아 있는 문제와 해결 방법

| 문제 | 해결 방법 |
|---|---|
| "실리콘 주방 트레이"는 네이버 검색량 10 미만 → 수요 요소 계산 불가 (NULL) | 이 키워드는 네이버 수요가 거의 없다는 뜻이다. 띄어쓰기 · 다른 표현(예: "실리콘 트레이" 560)으로 키워드를 바꾸거나, 다른 출처 검색량을 `/import` · 직접 입력으로 넣는다 |
| 실제 인증 실패 · 제한 응답은 실제로 겪어 보지 않음 | 생기면 `/import?job=` 수집 기록 사유로 확인 (코드는 모의로 검증됨) |
| 배포 환경(있다면)에는 키가 없음 | `.env.local` 은 이 PC 에서만 쓴다. 배포 서버에서 쓰려면 그 서버의 환경변수에 같은 세 값을 따로 넣어야 한다 |
| 판매량 · 전환율의 실제 출처 없음 → 실제 상품은 최종 판정 불가 | WING 판매분석(상품 등록 계정) 또는 출처가 확인된 외부 도구 파일을 `/import` 로 |
| 연결 상품이 많을 때 느릴 수 있음 | 상품마다 미리 보기 조회가 여러 번이다. 30개 상한을 뒀다. 실제 사용에서 느리면 일괄 조회로 줄인다 [제안] |
| 잠정 분석 순서를 순위로 오해할 수 있음 | 화면에 "추천 순위가 아님"을 표시했다 |

## 7. 내가 직접 수행해야 할 작업

### 7-1. 네이버 검색광고 API 키 — **완료** (적용 · 검증 끝)

- 키를 바꾸거나 재발급하면 `.env.local` 의 세 줄만 고치고 알려주면 된다 (서버 재시작 필요)
- 키 값은 채팅에 붙여 넣지 않는다

### 7-2. 판매량 · 전환율 출처 정하기

- WING 에 상품 1개 이상 등록 → 판매분석 화면 확인
- 또는 외부 도구의 실제 내보내기 파일을 하나 준비한다
