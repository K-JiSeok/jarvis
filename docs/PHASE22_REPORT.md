| 항목 | 쿠파일럿 공개 설명 | JARVIS |
|---|---|---|
| 판매량 | "리뷰 작성 확률 약 3%로 계산" · 상위 10개 상품의 최근 28일 매출 추정 · AI 모델 개발 중 | 같은 방식 채택. 3%를 가운데 값으로 쓰고, 1~5% 범위를 함께 표시 |
| 키워드 발굴 | 검색량 · 쿠팡 상품 수 · 경쟁 강도 · 윙 비율로 정렬 | 네이버 검색광고 검색량 + 연관 키워드 (기존) |
| 공급처 | 판매량 상위 상품 리뷰를 AI로 분석해 단점을 보완한 도매 상품 추천 + 1688 이미지 검색 | 일치도 → 원가 → MOQ → 연차 순 추천 + 1688 공식 확장으로 이미지 검색 |
| 마진 | 도매 상품 계산기로 마진 · 로켓그로스 수수료 · 최소 ROAS | 상세 원가(cost-detail-v1) + 원가 상한(신규) |

- 공급처 선정의 세부 기준과 공식은 공개돼 있지 않습니다 **[미확인]**.
- 쿠플러스(COUPLUS)는 크롬 웹스토어 설명상 "1688 상품 수집 · SKU · 발주서 · 판매현황 수집" 기능입니다. 공급처 선별 방식은 공개돼 있지 않습니다.

### 1-2. 이미 나와 있는 소싱 확장 프로그램

- **1688 공식**:
  - 「1688采购助手(구매 도우미)」: 1688 공식 개발자가 올린 확장. 스크린샷 · 이미지로 같은 상품 찾기
  - 「1688 AlphaShop」: 1688 공식 AI 소싱 · 이미지 검색
- 그 밖: AliPrice 등 서드파티
- **JARVIS에 연결하는 방식**: 다른 확장 프로그램의 내부 기능을 호출하거나 코드를 가져오지 않습니다(권한 · 보안 · 약관 문제). 대신 이렇게 이어서 씁니다.
  1. 쿠팡 상품 이미지를 1688 공식 확장으로 검색합니다.
  2. 나온 1688 상품 페이지를 엽니다.
  3. JARVIS [공급 후보 저장]을 누릅니다.
  4. JARVIS가 자동으로 추천 순서를 매기고 원가를 계산합니다.
- 소싱 대상 상품 카드에 이 안내를 넣었습니다.

### 1-3. 개발자 신청하면 승인되나

**보장할 수 없습니다.** 공식 문서상 조건은 다음과 같습니다.

- **1688 개방 플랫폼**
  - 신분 확인(诚信通 판매자 · 专业买家 · 跨境超买 등)과 기능별 자격 신청, 앱 심사를 거칩니다.
  - 해외 개인 · 한국 사업자가 어떤 자격으로 승인받는지는 공식 문서에서 확인하지 못했습니다 **[미확인]**.
- **Alibaba.com Open Platform**
  - 개발자 등록 → 앱 카테고리 신청 → 관리자 심사 → API 권한 신청 순서입니다.
  - 구매자용 "Buyer Sourcing Solution"(카탈로그 · 이미지 검색 · 유사 상품)은 "소싱 파트너 · 구매자 시스템" 연동용으로 설명돼 있어, 개인 셀러 도구로 승인될지는 불확실합니다.
- **권장**: 신청은 무료이니 해 보되, 승인 전에도 동작하는 반자동 흐름(1-2)으로 운영합니다.

## 5. 사용자가 할 일 (이것만 하면 숫자가 채워집니다)

1. **확장 프로그램 새로 고침** — `chrome://extensions` 에서 JARVIS [새로 고침]. 리뷰 날짜 읽기가 추가됐습니다.
2. **/discover "오늘 열어 볼 쿠팡 검색" 11개**를 열고 각각 [JARVIS 수집] → 다음 자동 실행에서 상품이 자동 등록됩니다.
3. **"오늘 수집할 상품 페이지"**를 열고 → 리뷰 [최신순] → [JARVIS 수집] → 판매량 추정이 나옵니다.
4. **같은 검색을 7일 뒤 다시 수집** → 리뷰 증가로 정확도가 올라갑니다 (신뢰도 C → B).
5. 마음에 드는 상품은 [후보로 선택] → [소싱 시작] → 1688 공식 확장으로 이미지 검색 → 1688 페이지에서 JARVIS 저장 → 추천 1순위와 원가 상한을 비교합니다.
6. **/profit/rates 비용 설정** (포워더 견적 · 과세 유형) — 확정 마진에 필요합니다.
