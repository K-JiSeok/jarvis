## 1. 왜

- 판정은 상품 단위지만, 좋은 상품은 좋은 시장(키워드)에서 나온다.
- 자동 수집은 주 1회 · 최대 20개라 **어떤 키워드에 수집 칸을 쓸지**가 발굴 속도를 정한다.
- 대기 중인 키워드 후보는 약 9,000개다(월 검색량 3,000 이상은 567개). 그동안은 검색량 순으로만 골랐다.

## 2. 새 화면 — 키워드 발굴(/keywords) 맨 위 [실제]

### 2-1. 키워드 기회 (추적 키워드마다)
- 표시: 시장 점수(판정 V2 의 시장 부분) · 근거 · 시즌 · 검색량 급증 · 마지막 수집일 · 판매 추정 상품 수 · 인증 필요 비율 · 최고 판정 · 다음 할 일.
- 단계와 순서: 판정 가능 → 판매 추정 대기 → 수집 필요 → 다시 수집 → 시장 부적합.
- 시장 점수 60 미만이거나 시장 위험이 2개 이상이면 **[추적 중지]** 버튼을 보여 준다. 누르면 자동 수집 칸이 빈다.

### 2-2. 수집 대기열
- 쿠팡 검색 결과가 없는 후보를 네이버 데이터와 단어만으로 먼저 거르고 순서를 매긴다 (kw-opportunity-v1).
- **거르는 것:**
  - 브랜드 (kw-filter-v2 로 보강)
  - 너무 넓은 키워드
  - 상품이 아닌 것: 렌트 · 대여 · 추천 · 가격 · 제작 · 가볼만한곳 등
  - 의류 · 신발 · 액세서리
  - 인증 부담이 큰 것: 전기 · 전파 · 가스 · 어린이 · 화장품 · 식품 · 의료 · 생활화학
  - 입고 때 비시즌인 것 (모기장 등)
  - 월 검색량 3,000 미만
- **점수:** 월 검색량 60%(1.2만~2.5만이 최고) + 네이버 광고 경쟁 40%.
  - 식품용 기구 −10, 시즌이 짧으면 −20, 구체적인 키워드 +5.
- **[실제] 567개 중 177개를 걸렀다.** 상위: 캠핑화로대 · 미끄럼방지매트 · 수납정리함 · 규조토발매트 · 피크닉매트 · 욕실발매트 · 데스크매트 · 캐노피천막 · 조립식창고 · 극세사담요.
- 지금 남은 자동 수집 칸은 9개(20 − 추적 11)다.
- 상품 발굴 화면의 [상위 N개 추적 등록]도 이제 이 대기열 순서를 따른다.
- 점수는 **수집 순서일 뿐 판정이 아니다.** 실제 판정은 쿠팡 검색 결과를 모은 뒤에 나온다.

## 3. 함께 고친 문제 (실제 데이터에서 발견)

### 3-1. 1,000행 제한 — 판매 추정이 조용히 틀어질 뻔했다
- Supabase API 는 한 번에 **1,000행까지만** 돌려준다. `.limit(20000)` 을 붙여도 잘리고 오류도 나지 않는다.
- 수집 원본(import_rows)은 이미 1,004행이라 넘었다. 리뷰 수 기록(product_snapshots, 787행)도 다음 자동 수집 때 넘는다.
  - 그러면 **오래된 리뷰 수 기록이 빠져 리뷰 증가 기반 판매 추정이 틀어진다.**
- **수정:** `src/lib/supabase/paged.ts`(`fetchAllRows`)로 1,000행씩 끝까지 읽는다. 적용한 곳:
  - 판매 추정 (`estimates.ts`) · 상품 맥락 (`sourcing.ts`)
  - 상품 목록 · 판매 가능성 목록
  - 자동 발굴 파이프라인의 카테고리 · 판매 가능성 단계
  - 추천 후보 스크립트 (`candidates.mjs`)
- **마지막 수집일:** 날짜 단위 뷰 `v_keyword_collection_days` 를 새로 만들어 읽는다(마이그레이션 · 운영 DB 적용 완료). 순위 행 전체를 읽던 방식은 1,000행을 넘으면 오래된 키워드의 수집일이 빠진다.
  - 이 뷰를 쓰는 곳: 확장 프로그램 자동 수집 대상 · 상품 발굴 · 키워드 기회.
- 1,000행에 아직 멀어 이번에 고치지 않은 곳: 상품별 키워드 순위 · 검색 관찰 · 가져오기 기록 · 네이버 상태.

### 3-2. 자동 수집이 검색 결과를 덜 읽었다
- [실제] 10-28 자동 수집의 칸 수는 수동 수집(10-13)의 절반이었다.
  - 차량용청소기 56 → 39, 식탁매트 50 → 21, 실리콘 트레이 41 → 20.
  - **캠핑랜턴은 2칸**뿐이었다.
  - 원인: 상품이 보이자마자 읽었다.
- **확장 프로그램 수정:** 1초마다 칸 수를 센다. 36칸 이상이 되거나, 10칸 이상에서 3초 동안 그대로면 읽는다 (최대 20초).
- **판정 수정:** 자연 순위가 10칸 미만이면 시장 구조를 쓰지 않는다.
  - 판정은 보류되고 "다시 수집 필요"를 표시한다. 시장 구조는 상위 10개 기준이기 때문이다.

### 3-3. 판매 가능성 규칙 보강 (compliance-rules-v2 안에서 추가)
- 가스용품 검사 규칙(신규): 토치 · 부탄가스 · 이소가스 · 캠핑버너 · 난로 등.
- 유선 전자기기 전자파 적합성평가: 키보드 · 마우스 · 헤드폰 · 이어폰 · 스피커 · 충전기 · 모니터 · 마이크.
  - 마우스패드 · 케이스 · 받침 같은 액세서리는 제외한다.
- 전기용품: 냉장고 · 전기그릴 · 다리미 · 온풍기 추가. 생활화학제품: 나프탈렌 · 좀약 추가.
- [실제] 등록 상품 518개 기준으로 PHASE 28 보다 새로 걸린 것은 캠핑 토치 1개(가스)다. 오탐은 없었다.
