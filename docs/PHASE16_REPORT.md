# JARVIS PHASE 16 — 실제 상품 발굴 실전 운영 · 데이터 확보 경로 검증 · 완료 보고서

작성일: 2026-10-12 · 대상: PHASE 16 커밋 (main)

> 표기
> - **[실제]** 실제 운영 DB · 실제 쿠팡 · 실제 네이버 API · 실제 화면에서 확인
> - **[모의]** 단위 테스트 · 모의 응답
> - **[미실행]** 실행하지 않음 (성공으로 세지 않음)
> - **[제안]** 승인 전 제안 (구현하지 않음)

**결론:** 실제 상품 5개를 처음부터 끝까지 수집 · 등록 · 분석할 수 있다.
- 최종 판정이 가능한 실제 상품은 **0개**다.
- 막는 것은 **판매량 · 판매 성장 · 전환율 (출처 없음)** 과 **가격 기록 3회 (시간 필요)** 다.
- 실제 원가를 넣으면 9개 요소 중 **5개**까지 계산된다.
- 위 네 가지가 채워져야 최종 판정이 가능하다.

### 3-1. `/discover` 결과 (실리콘 트레이) [실제]

| 상품 | 상태 | 계산 요소 | 비고 |
|---|---|---|---|
| 모나코올리브 (경쟁 4개 연결 · 관심상품) | 잠정 분석 · 최종 판정 아님 | **4/9** — 수요 11.2 · 경쟁 100 · WING 0 · 리뷰 장벽 77.3 | `[TEST]` 시나리오가 있을 때는 마진 87.27 까지 5/9 (가능 범위 37.5~72.5) |
| 나머지 4개 | 잠정 분석 | 2/9 — 수요 11.2 · 리뷰 장벽 77.66 (키워드 평균 리뷰 262) | 경쟁 관계가 모나코올리브 기준 한 방향이라 |

손 계산과 대조했다 (모두 일치).
- **수요:** 560 → 구간 (0,0)–(1000,20) → 11.2
- **경쟁 난이도:**
  - 경쟁 4개 가격 중앙값 (6,960 + 8,630) ÷ 2 = 7,795
  - 판매가 6,710 ÷ 7,795 = 0.86 → 100
- **리뷰 장벽:** 경쟁 리뷰 중앙값 (221 + 323) ÷ 2 = 272 → 80 − 72/800 × 30 = 77.3
- **WING 진입:**
  - 판매자 유형을 아는 경쟁 4개 (상품 페이지 수집 뒤: 직매입 3 · 로켓그로스 1) 중 WING 판매자 0% → 0점
  - **데이터가 있는 실제 0** 이다 (상품 페이지 수집 전에는 1개뿐이라 미계산)
- **`[TEST]` 수익성:** 판매가 6,710 · 원가 2,000 · 물류 1,200 · 수수료 10.8% · 광고 10% 일 때
  - 수수료 725 · 광고 671 · 총비용 4,596
  - 순이익 2,114 (31.5%) · ROI 105.7%
  - 손익분기 3,200 ÷ 0.792 = 4,041
  - 화면 값과 같다

**중복 제거** [실제]
- 모나코올리브는 검색 순위 · 경쟁 관계 · 관심상품 3경로로 연결됐지만 1번만 분석됐다
- 상품 마스터는 쿠팡 ID 기준 5행이다. 같은 상품을 다른 키워드에서 다시 수집해도 새 상품이 생기지 않는다 (선택 등록 결과 "기존 상품"으로 셈 — PHASE 12 검증)

## 6. 판매량 · 판매 성장 · 전환율 데이터 확보 가능 여부

### 6-1. 쿠팡 공개 화면 [실제]

- **판매량 · 전환율 · 조회수:** 없음
- **상품 페이지 "한 달간 N명 이상 구매했어요":**
  - 이번 4개 중 1개(소분용기)에 **"800명 이상"** 이 수집 기록(`payload.observedOnly.monthlyBuyers`)에만 남아 있다
  - **하한 구간**이라 판매량(실제 · 추정)으로 저장하지 않는다
  - 정확한 값이 아니다 [제안: 7절]

### 6-2. WING (판매자 계정)

| 항목 | 상태 |
|---|---|
| 사용자 계정 | PHASE 11 확인: "판매 준비하기 0/2", 등록 상품 0개 → 판매분석 · 유입경로 · 카테고리 분석 모두 "등록된 상품이 있어야 사용 가능" |
| 확인 가능한 데이터 (공개 안내 기준, 미확인) | 판매분석: **내 상품**의 판매량 · 매출 · 조회 · 전환 관련 지표 / 상품 조회 · 수정 표 머리의 "쿠팡 전체 판매량 / 지난 30일" 열 (PHASE 11 화면에서 열 이름만 확인) |
| 날짜 · 기간별 판매량 | 확인 못 함 [미실행] |
| 전환율 제공 | 확인 못 함 [미실행] |
| CSV · XLSX 내보내기 | 확인 못 함 [미실행] |
| `/import` 수용 | 컬럼(`sales_actual` · `sales_period_days` · `conversion_rate` · `views_28d`)과 출처 선택은 이미 있다. **실제 파일의 헤더 · 기간 표기를 봐야 별칭과 출처(WING_SESSION · A)를 확정할 수 있다** |
| 범위 | WING 판매분석은 **내 상품만**이다. 경쟁상품 판매량이 나온다고 가정하지 않는다. "쿠팡 전체 판매량" 열이 내 상품과 같은 상품(묶음)의 판매량인지는 상품을 등록해야 확인 가능하다 |

### 6-3. 외부 도구

- 사용자가 쓰는 도구의 실제 내보내기 파일이 없다 → **형식을 정하지 않았다**
- 기존 `/import` 는 그대로 둔다
- 받을 수 있는 컬럼은 아래와 같다
  - 상품 ID · 수집일 · 판매량 · 집계 기간(일) · 전환율
  - 기존 별칭: 추정판매량 · 예상판매량 · 판매량집계기간 · 전환율 · 구매전환율 · 28일조회수
- **외부 도구 판매량은 추정값**이다
  - `sales_estimated` 로만 넣는다
  - 출처 · 신뢰도를 고른다 (`ESTIMATED` · B/C)
- 샘플 파일 1개를 받으면 정확한 헤더 매핑을 확인할 수 있다

### 6-4. 활용 원칙 (지켜진 것)

- **실제 · 추정:** 따로 관리 (엔진 · 준비 상태 모두)
- **기간:** 30일 환산은 기존 규칙. 기간이 없으면 계산 불가
- **판매 성장:** 같은 종류 · 7일 이상 간격 · 90일 안 2회 (V1 그대로)
- **전환율:** 실제 출처가 없어 계산 불가 유지
- **추정값 생성:** 하지 않음
- **`[TEST]` 데이터 정리**
  - `[TEST] 원가 가정 (실제 원가 아님)` 시나리오: Profit Engine · `/discover` 연결 확인 후 삭제했다 (계산 1건 함께 삭제)
  - 남은 시나리오 0 · `[TEST]` 0

## 8. 최종 판정이 불가능한 정확한 원인

| 요소 (가중치) | 원인 | 해결되는 조건 |
|---|---|---|
| 판매량 (15) | 대상 · 경쟁 5개 모두 실제 · 추정 판매량 NULL. 쿠팡 공개 화면에 없음 | WING 판매분석(내 상품) 또는 출처가 확인된 외부 도구 추정치 + 집계 기간 → `/import` |
| 판매 성장률 (10) | 판매량 기록이 0회 | 같은 종류 판매량 2회, 7일 이상 간격 (90일 안) — **최소 7일 소요** |
| 전환율 (5) | 실제 출처 없음 | WING 판매분석의 실제 전환율 (내 상품만) |
| 시장 안정성 (5) | 가격 기록 1회 (오늘) | 날짜를 달리해 상품 페이지 2번 더 수집 — **최소 3일 소요** |
| 마진 (15) | 실제 원가 미입력 | 소싱 원가 · 물류비 · 수수료율을 넣어 대표 시나리오 저장 (바로 가능) |

**핵심:**
- 경쟁상품 판매량과 전환율은 공개 데이터에 없다
- 경쟁상품을 분석하는 단계에서는 출처 있는 추정 판매량(외부 도구)이 없으면 V1 규칙상 **최종 판정이 구조적으로 불가능**하다
- 전환율 요소(5점)는 판매자 계정에 상품이 있어야만 실제 값이 생긴다

**[제안 — 승인 필요, 구현하지 않음]**
1. 외부 도구 내보내기 파일 1개를 받아 `/import` 헤더 매핑을 확정한다 (코드 변경은 별칭 추가 정도)
2. "한 달간 N명 이상 구매" 하한값을 별도 지표로 보존하는 방식을 정한다
   - 판매량 칸에 넣지 않는다
   - 새 컬럼 또는 `metric_meta` 를 쓴다 → 설계 · 승인 필요
3. V1 의 "9개 모두 계산될 때만 판정" 규칙은 유지한다
   - 전환율처럼 경쟁상품 단계에서 원천적으로 없는 요소를 어떻게 다룰지는 규칙 변경 사안이다
   - 따라서 사용자 결정 사항으로 남긴다
4. 관심상품 목록에 최근 가격 · 순위 · 변화 열을 보여 주는 것 (지금은 상품 상세 이력으로만 확인)
