## 4. 자동 갱신 여부 및 실패 시 처리

- **자동 갱신하지 않습니다.** [실제] 판매자별 실제 요율표(WING 비용 상세 · 수수료 안내)는 판매자 로그인 화면이고, 이를 서버나 자동화로 긁어 오는 것은 허용 여부가 확인되지 않았습니다. 공개 API도 확인되지 않았습니다 [미확인].
- 대신: ① 시스템 요율은 "공식 페이지 수기 확인 (API 자동 갱신 아님)"으로 표시. ② 사용자가 WING 표를 복사해 붙여 넣으면 새 버전 행으로 추가 (붙여 넣기 해석기는 실제 화면 복사 글로 검증).
- 최신 여부 경고 [모의 + 실제 화면]: 확인한 지 30일이 지나면 경고 · 프로모션 종료 30일 전 경고 · 종료일이 지나면 자동으로 기본 비용으로 계산 · 경고 표시.
- 요율이 바뀌어도 과거 이력은 그대로입니다. 이력 행은 계산 당시 실제로 쓴 요율 행 사본을 갖고 있고, 수정 금지 트리거가 막습니다 [실제 — 운영 DB에서 UPDATE 시도 → 55000 거부].

## 13. 미완료 기능과 원인

1. **요율 자동 갱신** — WING 요율표는 판매자 로그인 화면 · 공개 API 미확인. 붙여 넣기 갱신만 제공.
2. **요율표가 있는 비용 분류는 2개뿐** (`주방 > 밀폐저장용기`, `주방 > 테이블웨어`) — 다른 분류 상품은 입출고 · 배송비를 "요율표 있는 분류 중 최저~최고" 추정으로만 계산. 판매 상품 분류가 정해지면 WING에서 붙여 넣어야 함.
3. **관세율 확정** — HS 분류 · 한중 FTA 세율 미확인 [미확인]. 0~8% 추정 범위 유지.
4. **간이과세자 계산** — 소매업 부가가치율 15% 가정 (세무 확인 필요). 매입세액 공제는 세금계산서 수취를 가정.

6. **보관 CBM 반올림 규칙** — WING 예시는 0.004CBM로 표기하지만 실제 반올림 규칙은 확인 못 함 [미확인]. 엔진은 정확한 부피 사용.
7. **공급 상품 · 쿠팡 상품 자동 수집** — 승인된 API 없음 (11절).
