## 1. 결정 사항 (사용자 위임)

목표: **쿠팡 로켓그로스로 팔았을 때 확실히 남는 상품**만 강력추천.

| 항목 | 결정 | 이유 |
|---|---|---|
| 전환율 | **있으면 가산 (최대 +5점)**, 판정의 필수 조건에서 제외 | 남의 상품 전환율은 공개되지 않아 필수로 두면 판정이 영영 나오지 않는다 (V1 문제). 내 상품 WING 전환율이 생기면 반영 |
| 광고비 | 판매가의 **15%** (이전 10%) | 신규 로켓그로스 광고는 목표 ROAS 300% 이상이 일반적 → 광고 매출의 약 33%, 출시 초기 매출 절반이 광고 경유로 보면 약 15% ([근거](https://inside.ampm.co.kr/insight/60609)) |
| 목표 순이익률 | **25%** (광고 · 수수료 · 물류 · 원가를 모두 뺀 뒤) | 이전 "마진 30% + 광고 10%"보다 광고를 현실적으로 잡고 합계는 더 엄격 (40% → 43%) |
| 빠진 비용 여유 | 판매가의 **3%** | 허용 원가 계산에 보관 · 반품 회수비가 없음 |
| 최소 월 판매 | 보수적 추정(리뷰 작성률 5%) **월 30개** | 리뷰 작성률은 믿을 만한 공개 자료가 없어 1~5% 범위의 가장 불리한 값으로 판단 |
| 주력 가격대 | 15,000~40,000원 (PHASE 23 그대로) | 1만원 미만은 로켓그로스 비용 비중이 너무 큼 |

가정값 · 근거는 `src/config/judge-assumptions.ts` 한 곳에 있고, **설정 화면**에 그대로 표시된다.

## 2. 판정 V2 구조

```
총점 = 시장 점수 50% + 상품 점수 50%
  시장 (키워드)  수요 30 · 리뷰 장벽 30 · 판매자 구성 30 · 광고 부담 10
  상품 (후보)    단위 경제성 45 · 판매 근거 35 · 가격대 20 · (+전환율 최대 5)
판정: 80 이상 강력추천 · 60 이상 검토 · 그 미만 제외  (핵심 5요소가 있으면 판정)
```

**확실한 수익 관문** — 점수가 높아도 판정을 낮춘다:
- 실제 공급 원가 미확인 → 강력추천 불가 (검토까지)
- 실제 원가 순이익률 10% 미만 → 제외, 25% 미만 → 검토까지
- 단품 · 묶음 모두 원가 여유 없음 → 제외
- 보수적 판매 추정 월 30개 미만 → 검토까지
- 시장 위험 2개 이상 → 검토까지 · 판매 불가 확인 → 제외

**신뢰도:** A = 실제 원가 확정 + 판매 근거 2개 이상 + 검색 결과 14일 이내 · B = 판매 근거 2개 이상(또는 쿠팡 표시 구매자 하한) + 14일 이내 · 그 외 C

**위험 자동 판정 9종:** 직매입 지배 · 광고 과다 · 리뷰 장벽 · 저마진 · 수요 부족 · 인증 필요 · 판매 불가 · 가격대 밖 · 오래된 데이터

단위 경제성 계산(unit-econ-v1 → **v2**)도 같은 가정값을 쓰도록 바꿨다.

| 상품 | 판정 V2 | 총점 | 시장 | 상품 | 신뢰도 |
|---|---|---|---|---|---|
| 실리콘 소분용기 얼음틀 (18,900원) | 검토 | 62.8 | 45.5 | 80.2 | C |
| 블리스온 싱크대 선반 (12,900원) | 제외 | 51.2 | 45.5 | 57.0 | C |

- 시장 점수가 낮은 이유: **월 검색량 550**(수요 11점) · **쿠팡 직매입 70%**(판매자 구성 40점). 리뷰 장벽은 낮다(82점).
- 신뢰도가 모두 C인 이유: 검색 결과가 **15일 전**(10-12) 수집이라 오래됨.
- 결론: 실리콘 트레이 시장은 진입 매력이 낮다. 다른 키워드(케이크토퍼 · 차량용청소기 · 방풍비닐 등, 월 검색량 1.3만~3만)는 판매량 추정이 없어 판정 보류 상태다.
